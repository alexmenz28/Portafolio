# Alexander Mendoza — Portfolio

Personal site built with Next.js, TypeScript, Tailwind CSS, and next-intl.

## Setup

```bash
npm install
npm run dev
```

- English: http://localhost:3000
- Spanish: http://localhost:3000/es

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Development server |
| `npm run build` | Production build |
| `npm run start` | Serve production build |
| `npm run lint` | ESLint |
